Pharmacy Software
Pharmacy Management System
A comprehensive web-based Pharmacy Management System built with Laravel to streamline pharmacy operations, manage inventory, process sales, and handle multi-branch coordination.

🚀 Features
Core Modules
Point of Sale (POS) System - Process sales transactions with invoice generation

Inventory Management - Real-time stock tracking with automatic low-stock alerts

Medicine Expiry Management - Automated expiry date notifications and prevention of expired stock sales

Purchase Management - Track supplier orders, deliveries, and purchase invoices

Multi-Branch Support - Facilitate inter-branch medicine transfers with automatic stock updates

User Management - Role-based access control (Admin, Pharmacist, Cashier)

Reporting System - Generate comprehensive reports in PDF and Excel formats

Sales Returns - Process returns and refunds with inventory adjustment

Security Features
Role-based authentication and authorization

Data encryption for sensitive information

Secure user session management

Protected access to financial and medical data

⚙️ Installation

1. Install PHP Dependencies
composer install

2.Start Development Server
php artisan serve

Visit http://localhost:8000 in your browser.
